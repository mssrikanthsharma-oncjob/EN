# Product Overview

## Enstructura Consultants Platform

A web-based structural engineering analysis platform designed for consultants to generate comprehensive assessment reports. The application streamlines the process of collecting field observations, test results, and photos to produce professional structural analysis reports with cost estimates.

## Core Functionality

- **Multi-step Data Collection**: Guided forms for observations, test results, photo uploads, and LLM configuration
- **AI-Powered Analysis**: Integration with LLM services (OpenAI, Anthropic) to analyze structural data and generate insights
- **Professional Report Generation**: PDF reports with multiple templates (standard, detailed, summary, compliance)
- **Cost Analysis**: Material estimates and cost breakdowns in Indian Rupees (INR) with regional pricing
- **Report History**: Storage and retrieval of previously generated reports
- **Authentication**: Simple login system for secure access

## Target Users

Structural engineers and consultants who need to:
- Document site visits and structural assessments
- Generate professional reports for clients
- Estimate remediation costs and materials
- Maintain historical records of assessments

## Key Features

- Responsive web interface optimized for field use
- Offline-capable data entry with local storage
- Multiple report templates for different use cases
- Indian market-specific pricing and currency formatting
- Photo documentation with metadata
- Validation and error handling throughout the workflow
