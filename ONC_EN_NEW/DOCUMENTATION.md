## Executive Summary

The Enstructura Consultants Platform is a comprehensive web-based structural engineering analysis system designed to streamline the assessment, documentation, and reporting processes for structural engineers and consultants. The platform integrates advanced AI-powered analysis with professional report generation capabilities, enabling engineers to produce industry-standard structural assessment reports efficiently and accurately.

## System Overview

### Core Architecture
- **Frontend Framework:** React 19.2.0 with TypeScript
- **Build System:** Vite 7.2.4 for optimized performance
- **Styling:** Tailwind CSS 4.1.18 for responsive design
- **PDF Generation:** jsPDF 3.0.4 for professional report output
- **AI Integration:** OpenAI and Anthropic LLM services
- **Data Persistence:** Local storage with offline capabilities
- **Deployment:** Vercel cloud platform with global CDN

### Key Features
- Multi-step data collection workflow
- AI-powered structural analysis
- Professional PDF report generation
- Multiple report templates
- Indian market-specific pricing (INR)
- Mobile-responsive interface
- Offline data entry capabilities
- Report history management
- Secure authentication system

## Usage Guide

### 1. System Access
Navigate to https://onc-en.vercel.app and authenticate using your credentials. The platform provides secure access control to ensure data confidentiality and professional compliance.

### 2. Data Collection Workflow

#### Step 1: Site Observations
- **Site Location:** Enter the project site address and location details
- **Engineer Information:** Record the lead engineer's name and credentials
- **Visit Date:** Document the site inspection date
- **Structural Issues:** Catalog identified structural problems with:
  - Issue type (crack, settlement, corrosion, deformation)
  - Severity level (low, medium, high, critical)
  - Location description
  - Detailed measurements and observations
- **Environmental Factors:** Record weather conditions, site access, and environmental considerations
- **Additional Notes:** Include supplementary observations and context

#### Step 2: Laboratory Test Results
- **Sample Identification:** Assign unique sample IDs
- **Test Types:** Document various testing methods:
  - Compression testing
  - Tension testing
  - Flexural testing
  - Chemical analysis
  - Custom testing protocols
- **Results Documentation:** Record test parameters, values, units, and specifications
- **Compliance Status:** Mark results as pass, fail, or marginal
- **Laboratory Certification:** Include accredited lab information
- **Technical Comments:** Add professional interpretations and notes

#### Step 3: Photo Documentation
- **Image Upload:** Capture and upload site photographs
- **Metadata Management:** Automatic file size, type, and timestamp recording
- **Preview System:** Review images before final submission
- **Base64 Encoding:** Secure image processing and storage

#### Step 4: AI Configuration
- **LLM Provider Selection:** Choose between OpenAI or Anthropic services
- **API Configuration:** Secure API key management
- **Model Selection:** Select appropriate AI models for analysis
- **Temperature Settings:** Adjust analysis creativity and consistency
- **Report Template:** Choose from available professional templates

### 3. Report Generation

#### Available Templates
1. **Standard Engineering Report**
   - Professional standard format
   - Executive summary, assessment, remediation, materials, costs
   - Ideal for routine structural assessments

2. **Detailed Technical Report**
   - Comprehensive technical analysis
   - Includes methodology, calculations, and references
   - Suitable for complex structural evaluations

3. **Executive Summary Report**
   - Concise format for stakeholders
   - Key findings, recommendations, and cost summary
   - Perfect for decision-maker presentations

4. **Code Compliance Report**
   - Focus on building codes and regulations
   - Compliance status and certification requirements
   - Essential for regulatory submissions

#### Report Features
- **Professional Cover Page:** Company branding with project information
- **Risk Assessment Indicators:** Color-coded severity levels
- **Structured Sections:** Consistent formatting and typography
- **Material Estimates:** Detailed quantity and cost breakdowns
- **Cost Analysis:** Comprehensive pricing in Indian Rupees (INR)
- **Professional Headers/Footers:** Page numbering and document metadata
- **Industry Standards:** Compliance with engineering report guidelines

### 4. Report Management
- **History Tracking:** Access previously generated reports
- **Version Control:** Maintain report versioning and updates
- **Export Options:** Download reports in PDF format
- **Storage Management:** Local storage with data persistence
